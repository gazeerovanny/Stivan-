# Stivan: демо-сайт мастерской

Одностраничный сайт мастерской Stivan (ремонт одежды, обуви и сумок, Москва, Новотушинский проезд, 8, корп. 1).
Чистые HTML, CSS и JS, без фреймворков и сборки. Главная идея: владелец сам правит услуги, цены, телефон, режим и акцию в Google Таблице.

Инструкция для владельца: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Структура

```
index.html            страница целиком (разметка, иконки, встроенная копия данных)
config.js             одна константа SHEET_CSV_URL: ссылка на опубликованную таблицу
css/styles.css        стили: светлая и тёмная темы на CSS-переменных
js/app.js             данные, каталог, подборщик, анимации
data/services.csv     услуги: группа, услуга, цена_от, комментарий, показывать
data/settings.csv     настройки: телефон, режим, акция (текст и вкл/выкл), Telegram, рейтинг
fonts/                Cormorant Garamond и Onest, урезаны до кириллицы и латиницы (лицензия OFL)
img/                  фавиконка, иконка для iPhone, обложка для соцсетей
tools/sync-fallback.mjs  обновляет встроенную копию данных в index.html
```

## Откуда сайт берёт данные

1. Google Таблица по ссылке `SHEET_CSV_URL` (формат CSV, «Опубликовать в интернете»).
2. Если ссылки нет или таблица недоступна: файлы `data/settings.csv` и `data/services.csv`.
3. Если и они недоступны (например, страницу открыли прямо с диска): копия этих файлов, встроенная в `index.html`.

Страница рисуется сразу из встроенной копии, потом тихо обновляется свежими данными. Последняя загруженная таблица запоминается в браузере посетителя, поэтому при сбое Google он видит её, а не стартовые файлы.

На одном листе таблицы лежат оба блока: сверху «настройка / значение», ниже «группа / услуга / цена_от / комментарий / показывать». Сайт находит блоки по строкам с названиями колонок. Пустые строки пропускаются, услуги с «показывать = нет» скрываются, строка без группы попадает в группу выше. Цена выводится как «от 500 ₽», без числа: «уточняйте у мастера».

После правки `data/*.csv` обновите встроенную копию:

```
node tools/sync-fallback.mjs          # обновить
node tools/sync-fallback.mjs --check  # проверить, что копия совпадает с файлами
```

## Посмотреть локально

```
python3 -m http.server 8000
```

и открыть http://localhost:8000. Можно открыть `index.html` двойным щелчком: сайт возьмёт встроенную копию данных.

## Публикация

Подойдёт любой статический хостинг (GitHub Pages, Netlify, обычный хостинг). После публикации замените в `index.html` значение `og:image` на полный адрес картинки, например `https://example.ru/img/og-cover.jpg`: соцсети не понимают относительные пути.

## Что проверено

Chromium через Playwright: ширина 320, 360, 375, 414, 768, 1024 и 1440 px без горизонтальной прокрутки; подборщик (сумма цен «от», частично без цен, текст заявки, переключатель, копирование); ссылки `tel:+79296010532`, `https://t.me/studiostivan?text=…`, VK и Яндекс Карты; таблица с ценами и акцией, недоступная таблица, открытие с диска, отключённый JavaScript, `prefers-reduced-motion`, переключение темы.

## Разведка и данные

Открыть stivan.ru и карточку на Яндекс Картах из среды, где собирался сайт, не удалось (доступ к этим адресам был закрыт). Поэтому:

- цены не заполнены, везде «уточняйте у мастера», владелец вносит их в таблицу;
- отзывы не цитируются, показан только блок «5,0, 303 оценки, 218 отзывов» и кнопка на Яндекс Карты;
- фотографий нет, вместо них нарисованные SVG-иллюстрации (джинсовый лоскут, пуговицы, катушка, иголка, выкройка), без людей и стоковых картинок;
- режим работы указан как «Работаем до 20:00», расписание по дням владелец добавит сам.
